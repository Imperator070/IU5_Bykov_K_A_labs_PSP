Описание товара

Пирометр-термометр Mastech MS6592P — универсальный измерительный прибор для бесконтактного и контактного измерения температуры. Подходит для использования в промышленности, быту и лабораторных условиях.

Прибор оснащён лазерным указателем для точного наведения на объект измерения. ЖК-дисплей с подсветкой обеспечивает комфортную работу в условиях недостаточной освещённости.

Особенности:

  • ✓ Бесконтактное измерение температуры от -50°C до +550°C
  • ✓ Контактное измерение с помощью термопары (в комплекте)
  • ✓ Лазерный указатель для точного наведения
  • ✓ Подсветка дисплея
  • ✓ Автоматическое отключение питания
  • ✓ Фиксация показаний (HOLD)
